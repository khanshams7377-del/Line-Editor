## Project Description

A simple command-line line editor written in C that allows users to create, view, and modify a small text document through terminal commands.

## Features

- Insert a line
- Delete a line
- Display the document

## Data Structure

The program uses an array of strings to store document lines.

## How to Compile

```bash
gcc line_editor.c -o line_editor.exe
