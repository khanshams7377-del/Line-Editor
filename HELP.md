# Simple Line Editor - Help

## 1. Insert Line

**Command:** 1

Enter the line number and then type the text to insert.

### Example
Enter choice: 1
Enter line number to insert: 1
Enter text: Hello

Output:
Line inserted successfully!

---

## 2. Delete Line

**Command:** 2

Enter the line number of the line you want to delete.

### Example
Enter choice: 2
Enter line number to delete: 1

Output:
Line deleted successfully!

---

## 3. Display Document

**Command:** 3

Displays all current lines with their line numbers.

### Example
Enter choice: 3

Output:
1. Hello
2. World

---

## 4. Exit

**Command:** 4

Closes the Line Editor program.

### Example
Enter choice: 4

Output:
Exiting Line Editor...
